# 项目概览

Transformer Learning Lab 面向神经网络零基础用户，长期目标是通过交互教材、数学动画、实验与代码实践，逐步理解《Attention Is All You Need》，实现简化版 Transformer。

## 已实现范围

- T01：Windows 本地 React 应用、五个页面、404、响应式布局、公共组件与基础路由。
- T01 后续使用修正：PowerShell 使用 `npm.cmd`；增加 `dev:lan`，便于同 Wi-Fi 下手机访问。
- T02：类型安全的课程数据模型、完整学习目录、独立正文占位、版本化本地记录、课时路由、数据校验与测试。
- T03：结构化教材引擎、KaTeX 公式与符号解释、Python/C 高亮复制、真实神经元参数演示、单选/多选/数值测验和第一节完整示范教材。
- T04：1～5 个输入的可视化神经元实验室，支持四种激活、六步前向传播、真实函数曲线、参数控制、教学示例与三项挑战；类型检查、两轮完整测试和生产构建均通过。
- T05：仿射层合并与非线性对照、真实导数/切线、1～8 层标量链式法则、同步函数比较及四项挑战，复用 T04 数学核心。实际验收结果见开发日志。
- T06：小型 MLP 结构编辑、矩阵前向、手写反向传播、MSE/Sigmoid+BCE、SGD、XOR 实际训练、损失曲线、决策边界与有限快照检查。最终验收结果见开发日志。
- T07：Unicode 分词、确定词表/ID、One-Hot、可编辑 Embedding、真实向量比较、正弦余弦 PE、八步输入矩阵流水线及 JSON 导出；升级两节教材。实际验收见开发日志。
- T08：Q/K/V 投影与元素解释、九步 Attention、稳定逐行 Softmax、缩放、Heatmap/Token 连线/贡献、多头 Concat/WO、Causal Mask、六项挑战和 T07 输入传递。四节正文复用原课时 ID；实际验收见开发日志。
- T09：真实 Post-LN Encoder–Decoder 前向、独立 FFN/Norm/层参数、矩形 Cross-Attention、共享 E/输出投影、架构图/张量流与概率；升级四节教材。实际验收见开发日志。

技术栈沿用 React 19、TypeScript 5.9、Vite 7、Tailwind 4、React Router 7、Lucide React；T03 新增本地 KaTeX、PrismJS，单元测试使用 tsx 加载 TS/TSX。没有付费服务或后端。

## 学习路线

| 课程 | 章节 | 课时数 |
| --- | --- | --- |
| 数学与神经网络 | 数学与神经网络入门；模型如何学习 | 5 |
| 语言的数字表示 | Token 与 Embedding | 1 |
| 理解注意力机制 | 从相似度到 Self-Attention；多个视角与序列位置 | 4 |
| 组装 Transformer | 网络中的辅助组件；Encoder 与 Decoder | 4 |
| 论文与实现路线 | 回到原始论文；Mini Transformer 实践 | 2 |

共 5 门课程、9 个章节、16 个课时。用户要求的 15 个主题全部包含；额外保留 T01 的“向量与矩阵的直觉”作为基础课时。T01 六个 ID 均保留，显示标题和层级可随课程演进调整。

## 当前边界

共 16 节中，神经元、MLP/反向传播、T07 表示、T08 Attention 及 T09 FFN/Encoder/Decoder/完整架构均有结构化正文，当前 12 节结构化、4 节占位。六座实验分别为 neuron、activation、neural-network、language-representation、attention、transformer（均在 /laboratory/ 下）。T03 参数小演示和旧入口继续可用；T05 仍是标量链式法则，T06 训练小型 MLP，T08/T09 只做前向。自动微分、代码执行、PDF 阅读器、账号、跨设备同步和 T10～T12 尚未实现。

测验记录在本次页面会话内按课时和块 ID 独立保存，页面内导航可保留，刷新清空；课时完成与最近访问记录继续使用 T02 localStorage，答题不会自动完成课时。

实验参数和挑战状态在实验组件内独立保存，离开实验页或刷新后重置；只在显式提交挑战时判定，不改变课程进度。T04 没有新增依赖或后端，图形由 SVG 和共用纯数学函数驱动。

T08 例外保存最近一份校验后的导入 X（独立键、v1、65536 字符上限），刷新恢复 Token/ID/shape/values 并提示投影参数重置；损坏或读取失败回退默认。页面内手动参数、挑战和播放状态不持久化。T07 自身配置仍在离开/刷新后重置。具体边界见 ATTENTION_MATH。

T06 模型/曲线/快照同样不跨刷新保存；当前模型、最近 300 个损失点、最近 12 个训练快照及额外固定的一份快照有明确区分。默认 2→4→1、Tanh/Sigmoid、种子 42、BCE、学习率 0.5、批量 4、2000 次更新能够正确分类 XOR 四样本；其他设置不保证收敛。任务路线现为 12 项，计划变更与历史状态见 TASKS。

学习记录从零开始，只在当前浏览器的同一站点来源保存；访问、学习中与完成不会混淆。清理站点数据或切换 IP/端口会影响可见记录。T01 的内存演示记录从未持久保存，因此没有需要导入的历史演示进度。

启动与检查见根目录 README；架构见 `ARCHITECTURE.md`；实际检查结果见 `DEVELOPMENT_LOG.md`。

T07 仅在浏览器内构造输入表示。默认 V=36、n=3、d=8，教学/随机向量均未训练；PE 使用论文 第 3.5 节 公式，当前实验未额外应用 第 3.4 节 的 √d_model 缩放。限制为 256 码点、32 Token、64 项词表及 2～16 偶数维度，非法输入不产生伪矩阵。实验配置刷新重置，原课时学习记录保留。
